# YandexMapsReviews - тест для hh

## Описание  
Проект представляет собой приложение состоящее из парсера с стороны бекэнда (PHP) и визуального интерфейса (Vue).

Для запуска приложения понадобится эмулятор браузера Salenium т.к у Яндекса есть защита против слабо настроеный скраперов(защита от роботов) 
и чтобы долго не настраивать сервисы между собой, будет использоваться Docker.

Использование бекэнд фреймворка для выполнения этой задачи, посчитал крайне избыточным как и реализация Регистрации/Входа,
т.к этот функционал почти вшит в Laravel даже в менее требовательные версии такие как Lumen и даже он является избыточным.

### Реализованный функционал: 
#### 1. Настройки:
- Интерфейс с полем для ввода ссылки на Яндекс карты в раздел с отзывами.
- Кнопка сохранения, при нажатии которой происходит валидация и переход в раздел с отзывами после подгрузки.
  
#### 2. Отзывы:
- Визуализация полученных данных с бекэнд-парсера.

#### 3. Страница авторизации:
- Сверстана, функциональна, но не связана с бекэндом, почему - описано выше.

## Установка  
- Необходимо установить Docker.
  
1. Клонируйте репозиторий:  
   ```bash  
   git clone https://github.com/Rellex2019/YandexMapsTest.git
   ```
   ```bash
   cd YandexMapsTest
   ```
2. Запутить сборку Docker
    ```docker
    docker-compose up -d --build
    ```
5. Готово
    #### Проект доступен по адресу [http://localhost:5173](http://localhost:5173)
